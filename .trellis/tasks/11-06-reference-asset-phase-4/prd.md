# Phase 4: Agent @资产包

## 目标与要求
Agent 输入支持 `@别名` 联想与派生 chip，提交显式 `{kind: "asset", collection_id}` 附件。后端在创建轮次的同一事务内按资产包顺序展开普通 input 行、分配标签，并在用户消息块中记录 `asset_refs` 快照。模型上下文以紧凑的 `[asset @alias: <ref ...>]` 行引用快照。

## 验收
- 联想、解析及附件和输入文本保持一致。
- 展开顺序、标签和快照正确，错误时事务回滚。
- 历史上下文、分支和重新生成稳定，不受资产包后续修改影响。
- 覆盖关键后端及前端行为，运行适用检查。
