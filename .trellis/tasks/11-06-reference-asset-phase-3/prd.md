# Phase 3: 选图器与资产管理 (Asset Picker and Collection Management)

## Goal

为前端用户提供资产包便捷注入与集合资产化管理能力：
1. **编辑器选图器**：在编辑源操作区新增“从资产包添加”弹窗，展示可用资产包/集合及其包含的光栅参考图，支持一键或按张多选批量注入到编辑源，包含容量检查与截断提示。
2. **集合别名管理**：在集合管理弹窗（`CollectionsDialog`）中支持查看、设置、修改和清除 `asset_alias`，前端联动校验与错误处理（唯一性冲突提示 409，格式规范拦截 422）。
3. **集合成员改序**：在集合管理弹窗中支持查看集合成员，并通过上移/下移或拖拽编排成员在资产包内的固定顺序（调用 `PUT /api/gallery/collections/{id}/items/order`）。

## Requirements

1. **集合管理弹窗支持别名配置 (`asset_alias`)**：
   - 集合行展示当前别名徽章（如 `@character_a`）；非空标识为资产包。
   - 提供别名编辑入口（设置/修改/清除）：
     - 限制字符集为 Unicode 字母、数字、下划线、连字符（长度 1–32），前缀不能为 `round-` 或 `第X轮图`。
     - 清除别名可传空或 null，恢复为普通集合。
     - 若服务端返回 409 冲突，展示友好提示（如“别名已被占用”）。
     - 若服务端返回 422 格式错误，展示格式限制提示。

2. **集合成员展示与改序管理**：
   - 在集合管理中增加“管理成员/查看参考图”抽屉或弹窗模式，通过 `GET /api/gallery/collections/{id}/references` 加载有序成员列表。
   - 展示成员缩略图、序号和文件名。
   - 支持上移（Move Up）和下移（Move Down）调整成员位置；保存时调用 `PUT /api/gallery/collections/{id}/items/order`，乐观更新并支持异常回滚。

3. **编辑器“从资产包添加”弹窗 (`AssetPackPickerDialog.svelte`)**：
   - 在编辑源卡片区（`EditSourcePicker`）增加“从资产包添加”按钮（附带图标）。
   - 弹窗展示所有具备 `asset_alias` 的资产包（或全部集合，资产包排在最前并高亮别名徽章）。
   - 点击资产包展示其有序参考图列表（排除了 SVG/GIF）。
   - 用户可以勾选部分或点击“全选/一键添加”。
   - 底部展示当前已选图片数与可用槽位计算：`当前已选 X 张，剩余可用槽位 Y 张（上限 16 张）`。
   - 点击“添加至参考图”后，调用 `editSourceStore.addGalleryReferences` 批量追加进编辑源；若超出槽位给出截断提示与已添加计数 toast。

4. **i18n 国际化**：
   - 补充中文（`zh-CN.ts`）与英文（`en.ts`）词条：资产包别名、设置别名、成员改序、从资产包添加、已选数量与容量提示等。

## Acceptance Criteria

- [x] 集合管理弹窗中可成功设置与清除 `asset_alias`，遇到别名冲突（409）或格式非法（422）展示友好错误。
- [x] 集合管理支持查看成员有序列表，可通过上移/下移重新编排成员顺序并成功持久化（调用 items order API）。
- [x] 编辑区提供“从资产包添加”按钮与弹窗，能够按资产包加载参考图片并进行多选。
- [x] 选图器展示剩余槽位容量，一键添加超出时自动截断至 16 张上限并弹出警告提示。
- [x] 选中的参考图成功追加至 `editSourceStore.galleryReferences`，并在工作区卡片列表中正常展示与支持删除。
- [x] 编写前端单元测试覆盖别名设置、成员重排与选图器添加逻辑，`npm run check` 零错误。
